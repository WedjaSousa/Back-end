# 🚀 Repositório Back-end (CRUD)

Este repositório contém o código-fonte do projeto de Back-end. O objetivo principal é fornecer uma API robusta para operações básicas de CRUD (Create, Read, Update, Delete).

## ✨ Funcionalidades Principais

* **C**reate (Criação de novos registros)
* **R**ead (Leitura e listagem de registros)
* **U**pdate (Atualização de registros existentes)
* **D**elete (Exclusão de registros)

## 🛠️ Como Instalar e Rodar o Projeto

Siga os passos abaixo para ter o ambiente de desenvolvimento funcionando em sua máquina.

### Pré-requisitos

### 1. Clonar o Repositório

Abra o terminal e clone o projeto:

```bash
git clone [https://github.com/WedjaSousa/Back-end.git](https://github.com/WedjaSousa/Back-end.git)
cd Back-end/backend-crud
```

### 2. Instalar Dependências

```bash
npm install
```

### 4. Rodar a Aplicação

```bash
npm start
```
